# Access Control Customer Profile

## Customer Type: ODM Customer
Rapidise can manufacture access control devices (readers, controllers, cameras) for these companies.

---

## Pattern Summary: What Makes an Access Control Customer Website

| Element | What to Look For |
|---------|------------------|
| **Headline** | "Access control", "physical security", "unified security" |
| **Products** | Card readers, door controllers, intercoms, keypads |
| **Often bundled with** | Cameras, intrusion detection, alarms |
| **Industries** | Enterprise, education, government, healthcare |

---

## Different Access Control Customer Types

| Type | Example | What They Need |
|------|---------|----------------|
| **Pure access control** | Acre Security | Readers, controllers |
| **Cameras + access control** | Verkada, Rhombus | Integrated solution |
| **Smart home security** | SimpliSafe, Ring | Consumer-grade access |

---

## Who Is NOT an Access Control Customer

- Locksmiths who install, don't brand products
- Building management companies (end users)
- Pure software providers (no hardware)
